# Git

- Default trunk branch is `main`, not `master`. Use `main` when creating branches, opening PRs, or referencing the trunk, unless a specific repo clearly uses a different name.
- Commits in this sandbox are authored as `Test User <test@example.com>` (forwarded from the host's global `git config`). Use this identity in any PR description, commit message, or GitHub interaction that needs to name the author.
